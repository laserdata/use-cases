# use-cases

A curated collection of real-world use cases, reference architectures, and code examples for LaserData Cloud, Laser SDK, and Apache Iggy.

Each folder is one use case: the problem, runnable tests, the published results and how to run them yourself.

| Use case | What it shows |
|---|---|
| [bounded-memory-under-pressure](bounded-memory-under-pressure/) | Memory and CPU of the Laser Streams server and Laser SDK clients through a 7-million-record consumer backlog, a 60-second server outage and restarts, measured on Google Cloud VMs |
